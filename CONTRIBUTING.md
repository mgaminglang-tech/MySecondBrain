# Contributing to MySecondBrain

Thank you for your interest in contributing.

MySecondBrain is an early-stage project exploring AI-assisted personal knowledge management. Contributions that improve documentation, reusable systems, templates, agent workflows, validation, and security are welcome.

## Before contributing

1. Read `README.md` to understand the project.
2. Read `AGENTS.md` before making repository changes.
3. Read `SECURITY.md` if your change involves credentials, sensitive data, or security behavior.
4. Search for an existing note or implementation before creating a duplicate.
5. Use sanitized or dummy data in examples and tests.

## Good contribution areas

- Documentation and onboarding
- Reusable knowledge-management systems
- Obsidian templates and workflows
- AI-agent instructions and safe operating patterns
- Validation and quality tooling
- Security improvements
- Examples using sanitized data
- Broken-link, Markdown, or repository-structure fixes

## Change guidelines

- Keep changes focused and explain their purpose.
- Preserve valid Obsidian Markdown, YAML frontmatter, wikilinks, embeds, queries, and template placeholders.
- Do not include secrets or sensitive personal/client information.
- Do not make unrelated reorganizations or destructive changes.
- Do not claim that a workflow, test, deployment, or integration was verified unless evidence exists.

## Pull requests

A useful pull request should explain:

- What changed
- Why it changed
- Which files or areas are affected
- How the change was validated
- Any limitations or follow-up work

Small, focused pull requests are preferred.

## Issues

Use GitHub Issues for reproducible bugs, documentation problems, security concerns that are safe to disclose publicly, and concrete feature proposals. Do not post secrets or sensitive personal/client information in issues.

## AI-assisted contributions

AI tools may be used to help prepare contributions, but the contributor remains responsible for reviewing the generated changes. Contributors should verify that AI-generated content does not invent facts, expose sensitive information, break Obsidian structures, or introduce unsafe instructions.
